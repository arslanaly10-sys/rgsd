Copied unchanged (minus agent config files) for use when working on this repo's UI:

| animate, motion, states, restraint, alignment, forms, copy, color | github.com/raphaelsalaja/skill | MIT, (c) 2026 Raphael Salaja |

Applied in the portal: motion only where it explains a change (dropdowns open from their trigger,
status messages ease in), under 300 ms on `cubic-bezier(0.23, 1, 0.32, 1)`, reduced-motion respected;
one button and card system; every state (empty, view-only, overdue, error) designed; illustrations
badged and never passed off as site photos.

`impeccable` (npm) was reviewed but not installed: it is a CLI that downloads further content at install time.
